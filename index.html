🤖 AI Scheme Update Pipeline

Official Source → AI Extraction → Verification → Publish

SchemeAI is designed so that new scheme information can be collected from selected official government sources, structured by AI, reviewed by an administrator and then published to the scheme database.

The current website is a prototype. Live automatic source monitoring and database publishing require a backend service.
